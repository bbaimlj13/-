# 分布式新闻爬虫系统

一个基于Scrapy-Redis和FastAPI的高性能分布式新闻爬虫系统，支持多节点部署、实时监控和自动扩展。

## 功能特性

### 🚀 高性能架构
- **分布式爬取**: 基于Scrapy-Redis实现多节点并行爬取
- **容器化部署**: 支持Docker和Docker Compose一键部署
- **自动扩展**: 可根据负载动态扩展爬虫节点

### 📊 智能管理
- **Web控制台**: 基于FastAPI的现代化管理界面
- **实时监控**: 提供完整的系统监控和性能指标
- **任务调度**: 支持定时任务和优先级队列

### 🛡️ 稳定可靠
- **断点续传**: Redis持久化队列，支持任务恢复
- **错误重试**: 智能重试机制和错误处理
- **健康检查**: 完整的系统健康监控

### 📈 数据管理
- **多种存储**: 支持MySQL、MinIO对象存储
- **图片处理**: 自动图片下载、压缩和存储
- **附件管理**: 支持PDF、Word等附件处理
